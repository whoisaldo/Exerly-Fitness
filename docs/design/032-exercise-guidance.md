# Exercise guidance while logging

A beginner needs to know how to perform a movement without leaving the active
workout. The existing exercise details screen lists muscles and tracking
fields but gives no setup or movement instructions. Put a short technique
guide first, with metadata below it. Link the same guide from the active
exercise and the library. Opening it must not change sets or the rest timer.

Keep the existing purple/pink identity. Use a clear movement title, a concise
purpose statement, Setup and Movement cards, and one control cue. References
open their original public pages; do not copy or redistribute media without
a license. The written cues are original and checked against primary exercise
references. Never invent instructions for an unknown/custom exercise.

Start with the common movements in generated beginner plans and expand
coverage in passing pieces. Until original or licensed demonstrations are
available and device checks pass, T02 remains Partial. A catalog check must
keep guide keys aligned with the Core exercise IDs. Exercise matching and
workout calculations remain in Core.

Native verification: open guidance from a workout and from library search,
return to the same session, preserve exact set values and running rest timer,
and keep the guide available offline. Inspect default light/dark and largest
text, compare with the public workout references, then land the slice.
